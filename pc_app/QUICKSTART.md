# FerroDSP Lab — переносимая версия Windows

[Русский](QUICKSTART.md) | [English](QUICKSTART.en.md)

1. Скачайте `FerroDSP-Lab-…-windows-x64.zip` из Releases репозитория
   https://github.com/neuroandriyanov/FerroDsp/releases .
2. Распакуйте **весь ZIP** в доступную для записи папку, например `Документы\FerroDSP-Lab`.
3. Запустите `FerroDSP-Lab.exe`. Python, pip, SigmaStudio и отдельный видеокодек
   для этой программы устанавливать не требуется. Интернет во время работы не нужен.

Не переносите только EXE: папка `_internal` обязательна. Настройки и опыты появятся
в `UserData/local` и `UserData/recordings` рядом с EXE. Для обновления распакуйте
новую версию отдельно, затем скопируйте в неё свою `UserData`, сохранив резервную копию.
При переносе на другой стенд заново задайте плоскость катушки, пустой фон и фон фазы.

## Оборудование

Windows 10/11 x64, свободное место для записей (контроль: минимум 2 ГБ),
RealSense D415 на USB 3 и вход S/PDIF с поддержкой **96 кГц, стерео PCM24,
WASAPI exclusive**. Драйверы устройств Windows должны быть установлены.
Для графиков необходим проект DSP с протоколом `ferrodsp-am-iq-v1`; произвольный
стереосигнал не является четырьмя каналами I/Q. Его схема описана в
`Source/pc_app/resources/transport-protocol.json`.

Программа сама подключается к устройствам; если устройство отсутствует,
окно останется доступным с сообщением. В «Настройки захвата» выберите S/PDIF-вход.
Закройте другие приложения, занявшие камеру или аудиовход. Программа не изменяет
прошивку и настройки металлоискателя. Распознавание металлов пока не реализовано.

Перед записью добавьте образец в таблицу, настройте плоскость катушки и пустой фон.
Подробное руководство: `Source/pc_app/README.md`.

## Диагностика и управление

Запуск без подключения устройств:

```powershell
.\FerroDSP-Lab.exe --no-connect
```

Проверка библиотек, декодера и записи файлов без захвата устройств:

```powershell
Start-Process -FilePath .\FerroDSP-Lab.exe -ArgumentList '--self-test self-test.json' -Wait
Get-Content .\self-test.json
```

Результат должен содержать `"ok": true`. Журнал ошибок: `UserData/local/application.log`.
`FERRODSP_DATA_DIR` позволяет задать другую доступную для записи папку данных.
Локальный API описан в README; адрес и токен текущего процесса находятся в
`UserData/local/control.json`. Их не нужно публиковать или переносить между ПК.

Версия предварительная; проверена на текущем стенде Windows. Готовый ZIP следует
дополнительно проверить на целевом ПК. Синхронизация использует общую шкалу времени
ПК; физическая задержка камеры и аудиотракта пока не откалибрована.
