# FerroDSP Lab 0.1.0-preview.1

Первый переносимый выпуск для Windows x64: запуск EXE без отдельной установки
Python и библиотек. Включены SDK RealSense, Qt, обработка сигналов, HDF5 и FFmpeg.

* D415: цвет/глубина 640×480, наложение и настройка прозрачности.
* Четыре комплексных канала I/Q через стерео S/PDIF `ferrodsp-am-iq-v1`.
* Графики фазы, амплитуды и расстояния на общей шкале времени.
* Данные для анализа: исходный PCM24, Z16, RGB, I/Q, временные метки и маски качества.
* Демонстрационный H.264 MP4 с названием образца и тремя графиками.
* Отдельная папка пользовательских данных, локальный API, журнал ошибок и самопроверка.

Файлы стенда, калибровка положения камеры, токены и записи в выпуск не входят.
Калибровка транспорта и его описание включены; применимость к изменённому DSP
или аудиотракту нужно проверять. Это инструмент исследования, не готовый
классификатор металлов и не измеритель физически откалиброванной задержки.
